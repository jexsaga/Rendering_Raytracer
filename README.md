MinimalPBR

A minimal CPU/GPU physically based renderer.

The objective is not performance.

The objective is understanding.

The project follows the evolution of a renderer from a
single ray-triangle intersection to a progressive Monte
Carlo path tracer.

The code is intentionally kept as small as possible while
remaining scientifically correct.
